Design details
4
Icons show what's logged. Each child row shows a colored icon for each logged entry type. Dashed empty slots hint at what's still missing (for example, no nap logged yet).
5
Status in three ways. The avatar dot, the badge text and the filter chips all show the same status, so it never depends on color alone.
6
Tap to expand. A child row opens to show today's entries, with Add entry and Preview report. Each entry opens for edit or delete.
7
Record button. An 84px apricot button docked in the tab bar, reachable by the thumb. Hold to record, or tap once to start and tap again to stop.
8
Privacy in copy. “Finger painting with a friend” instead of naming the other child, because this text flows into the parent report.
